# Accessibility Pack

Accessibility-oriented controller assistance:
- Hold-to-mash Cross
- Optional hold-to-mash Circle
- Optional hold-to-mash Square
- Adjustable repeat interval
- Optional automatic in-level cutscene skip

The turbo logic inserts release ticks while the physical button remains held, creating repeated press edges.

Built for OpenRAC RAC1 PAL/NTSC-U. AI-assisted implementation. GPL-3.0-or-later.

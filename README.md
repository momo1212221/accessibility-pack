# Accessibility Pack

Controller accessibility helpers for RAC1:

- Hold-to-mash Cross.
- Optional hold-to-mash Circle.
- Optional hold-to-mash Square.
- Adjustable repeat interval.
- Shoulder-button chords are preserved so other QoL shortcuts continue to work.

This mod **never skips cutscenes** and does not modify story progression.

Better Pause Menu / QoL Hub can display its current settings, while the runtime input assistance remains in this standalone background mod.

No game assets or disc files are included.

Built for OpenRAC RAC1 PAL/NTSC-U. AI-assisted implementation. GPL-3.0-or-later.
